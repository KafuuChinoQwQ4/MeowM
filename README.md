# MeowM 本地优先个人账本

MeowM 是一款以 Android 为主、离线可用的个人收支管理应用。账本数据保存在本机 SQLite 中，界面使用 Tauri、React 和 TypeScript 构建，账务逻辑由 Rust 处理。每个平台可选择自己的币种，金额按该币种的最小单位保存；收支报表统一折算为人民币。

## 功能

- **账本与平台：** 按日期查看收支和余额，管理钱包、银行卡、现金等平台，创建平台时可选择人民币、美元、欧元、日元等 11 种币种。记录外币收入、支出和退款时按原币录入，并预览折合人民币金额；已保存交易会保留当日汇率快照。转账仅支持同币种账户。
- **流水与待确认：** 查看、修改流水；导入的账单和采集到的交易先进入待确认，核对后再计入账本。
- **账单导入：** 支持微信、支付宝和银行卡的 CSV、XLS、XLSX 文件，预览记录并识别重复项。
- **财务管理：** 查看收支报表、管理预算和周期账单，搜索流水、整理分类规则，并按平台余额和流水进行对账。
- **Android 采集：** 经用户授权后，可读取支持的支付通知或识别支付页面；识别结果仍需在待确认中核对。
- **安全与数据：** 支持应用锁、自动锁定、隐藏金额、加密备份与恢复，以及 CSV/JSON 导出和数据清理。
- **汇率趋势与换算：** 在 CNY、USD、EUR、JPY、HKD、GBP、KRW、AUD、CAD、SGD、CHF 中任选源币和目标币，输入金额查看参考换算；历史 K 线图可点击近 7、30、90、180、365 天切换查看，并显示对应日期区间。交叉汇率使用双方同一有效日期的 CNY 参考价计算。换算结果只作参考，不产生账务流水。Android 联网时由系统后台任务每日尝试更新，执行时机受 Android 调度和省电影响；参考汇率不是实时成交报价。交易日期前没有可用的本地汇率时，可手动填写汇率；该值同样会随交易保存。虚拟币与股票行情可在独立板块扩展。
- **OKX 加密资产与交易：** 欧易公开行情、自选交易对及 K 线无需 API Key；可选配置只读 API 查看账户资产、账单、现货成交、充提记录和合约表现。现货、永续及交割合约支持市价/限价买卖或开平仓；模拟盘为默认环境，实盘使用单独的交易凭据，并且每笔订单都要经过预览和再次确认。未确认的下单结果需按原客户订单号查询，不会自动重试。应用不申请提币权限，也不修改杠杆或账户持仓模式。
- **加密流水核对：** 支持最近 7 天/3 个月账户账单、近 3 个月现货成交和充提历史，逐页导入、去重并人工确认或忽略。现货成交保留两种资产数量和独立手续费；未成功完成的充提不可确认。加密记录独立保存，支持加密备份与恢复，不计入法币账本收支。

## 使用

启动应用后，可从底部导航进入「账本」「明细」「待确认」「法币汇率」「财务管理」或「设置」。创建平台时选择币种；币种创建后不可更改。手动外币收支会显示人民币折算预览和汇率来源。汇率趋势页可以任意选择两种币种换算金额和查看历史曲线。报表的收入、支出和结余以人民币统计，平台余额以账户原币显示。退款需要与原消费币种一致；账户间转账要求同币种。账单导入、通知采集和待确认只支持人民币平台。通知采集和支付页面识别可在「设置 → 平台与采集」中配置，使用时需要授予相应的 Android 系统权限。

桌面开发需要 Rust、Node.js/npm 和 Tauri 所需的系统依赖：

```bash
cd apps/tauri-ui
npm ci
npm run tauri -- dev
```

OKX 的凭据在「交易所 → 欧易 → API 凭据设置」中按用途分别填写：行情和 K 线公开可读，无需设置；资产、账单、成交和充提查询使用用户自己的只读 API；模拟盘和实盘交易使用各自独立的 Trade API。凭据由本机系统安全存储保管，不进入备份。交易流程不使用 Withdraw 权限，也不提供转账、杠杆修改或账户模式修改。每笔订单先刷新产品与账户信息，再由用户检查预览并确认；模拟盘默认开启，切换实盘后页面会警示真实资产风险，仍需逐笔确认。网络结果不明确时，先按相同客户订单号查询以核对状态。加密流水按 OKX 账户 UID 和平台记录编号去重，重复导入保留人工确认状态；已确认充提如需重新核对，可先移回待确认。账单核对项与成交、充提可能描述同一事件，投资表现只统计持仓接口的净盈亏，避免重复累计。合约 `realizedPnl` 已含手续费和资金费，费用分项不再次扣除。接口字段及范围见 [OKX API v5 官方文档](https://www.okx.com/docs-v5/en/)。

币安默认进入现货行情页，展示全部在交易中的现货交易对，支持币种、报价币和中文名称搜索、下滑查找、自选及分周期 K 线；公开行情不需要密钥。资产总览按币种显示生产现货账户的可用和冻结余额，需要在「API 凭据设置」保存只读凭据。同花顺 iFinD 提供股票名称搜索、完整代码直达、官方 A 股列表、自选、最新报价和不复权日/周/月 K 线，需要有效 Refresh Token 及对应数据权限；名称搜索使用官方智能选股服务。两个平台的自选各自保存在当前设备，最多 100 项，不含凭据，不随账本备份。原有接口目录保留在「更多接口」中。

构建 Android 调试 APK 需要 JDK 17、Android SDK/NDK 及对应的 Rust target。配置 `ANDROID_HOME` 和 `ANDROID_NDK_ROOT` 后运行：

```bash
rustup target add aarch64-linux-android
bash scripts/build_android.sh arm64-v8a
```

详细 Android 构建参数见 [`scripts/build_android.sh`](scripts/build_android.sh)，项目模块说明见 [`docs/architecture.md`](docs/architecture.md)。
