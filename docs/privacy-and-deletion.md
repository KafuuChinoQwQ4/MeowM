# 本地数据、权限和删除

账本保存在应用私有 SQLite 中，金额使用整数。没有用户账号、服务端、网络权限、遥测或自动云同步。Android 自动备份和设备迁移均禁用；手动导出的加密文件由用户选择位置，可能位于云盘，请自行控制其保存与删除。

通知权限由用户在系统设置授权。微信、支付宝来源默认关闭，关闭来源仅阻止后续采集，不删除已有交易。未支持银行通知与通用银行 CSV；API 开关仅保存未来接入意向，当前没有真实联网适配。系统/厂商可能丢失、隐藏或限制通知，不能保证完整捕获。

通知正文仅瞬时传入 Rust 解析，不存储到 SQLite 或普通日志；持久化的是标准化金额、商户、账户线索、来源身份与摘要。CSV 缓存位于私有 cache，读取完成后删除；加密备份缓存恢复成功/下次启动清理。应用不打印通知、原始账单行、备注、账户名、密码或 Token。错误只在本机 UI 显示；没有崩溃上传组件。禁止在故障排查中添加原始 payload 日志。release APK 不打包测试账单/测试凭据。

设置中可选设备 PIN、图案或密码应用锁；先通过系统认证再启用。离开应用后重新进入需认证，取消保持锁页，Back 退出任务；账本/设置窗口在锁定期间隐藏，FLAG_SECURE 禁止系统截图及最近任务内容。应用锁保护界面访问，不加密本地 SQLite，也不阻止用户已授权的后台通知采集；设备本身仍应启用锁屏和存储加密。密码仅经系统验证，不由应用保存。

## 删除规则

编辑交易页：勾选确认后删除当前交易及其全部证据。若原支出仍被任何退款引用，拒绝删除，先删退款。

设置页：选择批次并勾选确认后删除整批。该批来源证据被删除；仍有其他批来源证据的共享交易保留。仅属于该批的交易一并删除。若保留的退款引用将删除的原支出，整个操作拒绝；同批支出与退款可同时删除。所有 SQLite 修改在一个事务内，异常完整回滚。

全部本地删除：先关闭 Android 通知偏好与 JNI 采集，再在 SQLite 单事务中清理交易、postings、证据、批次、账户、分类、规则、Pending 详情并重置 mobile_settings/provider_settings。随后删除三个 provider credential 密文槽及其 Keystore alias、CSV/备份 staging，并关闭应用锁。SQLite 与 Android Keystore 不共享事务；若后续安全存储清理失败，UI 明确显示未完成，请重试全部删除。已删除的账本不会恢复，采集继续关闭。清理正在进行文件操作时拒绝执行，以避免异步缓存重新出现。

SQLite 开启 secure_delete 覆盖删除页中内容；这不是闪存物理销毁保证。用户导出的备份、来源账单、系统外部副本不受本机删除影响，需要自行删除。删除证据也删除去重身份，用户之后主动重新导入已删除来源可以重新入账。

## 导出与恢复

设置启用备份，输入至少八字符密码并勾选操作确认，之后才导出。恢复前选择文件、输入密码并勾选覆盖确认。使用 AES-256-GCM + Argon2id，错误密码、损坏、未知版本、无效账务或写失败均不部分替换账本。恢复采用完整覆盖，不支持合并；授权保持本机选择。Android SAF 取消不改账本，写失败会尝试删除新建的不完整目标文件，但第三方文件提供器不保证跨提供器原子提交。

凭据采用 Android Keystore 不可导出 AES 密钥加密，仅密文位于 noBackupFilesDir，不进入数据库与手动备份。当前没有真实 API 授权/联网能力。删除本机凭据不等于远程平台撤销授权。
