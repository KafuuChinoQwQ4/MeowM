# 第八阶段：加密备份、恢复与数据导出验收

验收日期：2026-10-16。对应九功能计划 Task 8；未进入 Task 9 的隐私控制与数据生命周期开发。

## 实现范围

- 从 SQLite 一致性事务生成带 schema 版本的白名单快照。保留平台、分类规则、交易和分录、来源去重证据、导入收据、预算、周期账单、通知设置、对账快照及审计。只携带 `hide_amounts` 偏好；应用密码和系统权限仍留在本机，通知原始正文未入库，也不会进备份。
- 先在独立内存 SQLite 中按可信迁移重建、验证，再用立即事务完整替换当前账本。检查外键、SQLite 完整性、账户/交易/预算/周期/对账关系。失败回滚；预览后账本变更或十分钟超时会拒绝恢复。备份、恢复和导出单文件上限 32 MB，快照最多 20 万行。
- 文件头记录格式版本、随机盐和随机 nonce；使用 Argon2id 派生密钥并以 XChaCha20-Poly1305 认证加密。文件头参与认证；密码不保存。解密后校验归档版本、创建时间和快照摘要。旧 schema 快照在临时库迁移到当前 schema 9，未知版本拒绝。
- CSV/JSON 导出基于冻结快照与同一搜索条件，默认只含已确认交易，可显式选择其他状态。金额用字符串，记录退款、冲销、分录和来源类型；CSV 可选 BOM，并保护文本字段免于被表格软件当作公式执行。导出只读，结果未加密。
- React 页面分开创建备份、选择文件并预览恢复、筛选导出。Android 使用系统 Storage Access Framework 选文件/选保存位置，桌面使用浏览器文件选择与下载。

## Android 实际链路

在 API 35 x86_64 模拟器覆盖安装调试 APK，通过实际 WebView 调用 Rust，未注入模拟 IPC：

1. 从当前活动库（7 个平台、2 条交易）创建加密备份；错误密码被拒绝，正确密码预览显示对应表数量；JSON 导出返回 2 条交易。
2. Android 系统“另存为”选择器写出 `.meowm` 文件；拉回后与 Rust 生成的密文逐字节相同。
3. Android 系统“打开文件”选择器读回该文件；读取内容逐字节一致，检查预览后完成恢复。
4. 测试前先逐字节备份设备当前活动库，测试结束强制停止应用并恢复原文件；SHA-256 与测试前一致，文件所有者和权限恢复。

此处验证的是 x86_64 模拟器上的 WebView、IPC、加密、SQLite 和系统文件选择器链路；未在 ARM64 真机或第三方文档提供器上验收。导出文件由用户保管，不提供云同步或密码找回。恢复采用完整替换而非合并；账户、交易等会被覆盖，本机安全凭据及权限保留。
